# PW Staff Bot — Perfect World 1.3.6

Telegram-бот для регистрации игроков, опросов и учёта посещений в Google Sheets.

## Настройка Bothost

Python 3.11+, главный файл `bot.py`, зависимости `requirements.txt`.
Переменные окружения:

| Переменная | Значение |
| --- | --- |
| BOT_TOKEN | Токен Telegram из BotFather |
| ADMIN_IDS | Числовые ID администраторов через запятую |
| DATA_DIR | `/app/data` для постоянной SQLite-базы |
| GOOGLE_SHEET_ID | ID Google-таблицы |
| GOOGLE_CREDS | JSON сервисного аккаунта Google целиком |
| OCR_SPACE_API_KEY | Ключ OCR.space для распознавания скриншотов |

Сервисному аккаунту нужен доступ редактора к таблице; включите Sheets API и Drive API.
Не сохраняйте ключи и токены в репозитории.

## Таблица

Исходный лист — `Новый шаблон`. Заголовки могут располагаться в первых шести строках.
Нужны `НИК`, `РБ`, `Комендант`, `Баньши`, `ГВГ`, `зп 1/2`, `зп 2/2`.
Даты событий располагаются под заголовками до первой строки игрока.
Разделы классов в B или C: МАГИ, ВАР/ВАРЫ, ДРУЛИ, ТАНКИ, ЛУЧНИКИ, ПРИСТЫ.

Бот создаёт `Активность MM.YYYY` по московскому времени. Если лист с таким названием
уже использует старый формат, новый получает суффикс ` (136)`.
Существующий лист старого формата не изменяется.

При создании месяца сохраняются состав, оформление и формулы шаблона; копии отметок
посещения и ручных капитанских очищаются. Даты переносятся на тот же день нового месяца;
несуществующие даты (например, 31 февраля) очищаются. Расписание по дням недели автоматически
не пересчитывается: перед использованием нового месяца проверьте даты в его заголовках.

`/sync_pa` добавляет подтверждённых пользователей в свободные строки нужных классов текущего месяца.
Уже имеющиеся строки и их результаты не переставляются. Для новых строк заранее подготовьте формулы.
Если раздел заполнен, бот попросит добавить строку с формулами вместо перезаписи игроков.
После подтверждения заявок синхронизация выполняется автоматически; `/start` синхронизирует профиль игрока.

## Фото и явка

Админ-панель → Управление кланом → Активность игроков → фото списка ников.
После OCR бот показывает сопоставленных игроков; неизвестные ники пропускаются.
Выберите событие, дату, ПЛ (или «Без ПЛ»), проверьте список и нажмите «Записать».
ПЛ получает `2`, участники `1`. Повторная запись в ту же дату не создаёт дополнительного посещения
и не уменьшает `2` до `1`. Исправление ошибочной отметки выполняется вручную в таблице.

Зарплата читается из результатов формул `зп 1/2` и `зп 2/2`; бот не заменяет формулы своим расчётом.
OCR.space получает отправленное изображение для распознавания.

## Проверка

`python -m unittest -v test_flows test_sheet_layout`

Тесты используют временную SQLite и поддельную таблицу; Telegram, OCR и Google API не вызываются.
