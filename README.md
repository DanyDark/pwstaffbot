# PW Staff Bot — Perfect World 1.3.6

Telegram-бот для регистрации игроков, опросов и учёта посещений в Google Sheets.

## Настройка Bothost

Python 3.11+, главный файл `bot.py`, зависимости `requirements.txt`.
Переменные окружения:

| Переменная | Значение |
| --- | --- |
| BOT_TOKEN | Токен Telegram из BotFather |
| ADMIN_IDS | Числовые ID администраторов через запятую |
| DATA_DIR | `/app/data` для постоянной SQLite-базы |
| GOOGLE_SHEET_ID | ID Google-таблицы |
| GOOGLE_CREDS | JSON сервисного аккаунта Google целиком |
| OCR_SPACE_API_KEY | Ключ OCR.space для распознавания скриншотов |

Сервисному аккаунту нужен доступ редактора к таблице; включите Sheets API и Drive API.
Не сохраняйте ключи и токены в репозитории.

## Таблица

Исходный лист — `Новый шаблон`. Заголовки могут располагаться в первых шести строках.
Нужны `НИК`, `РБ`, `Комендант`, `Баньши`, `ГВГ`, `зп 1/2`, `зп 2/2`.
Бот записывает даты событий под заголовками при сохранении посещения.
Разделы классов в B или C: МАГИ, ВАР/ВАРЫ, ДРУЛИ, ТАНКИ, ЛУЧНИКИ, ПРИСТЫ.

Бот создаёт `Активность MM.YYYY` по московскому времени. Если лист с таким названием
уже использует старый формат, новый получает суффикс ` (136)`.
Существующий лист старого формата не изменяется.

Лист проверяется автоматически при запуске и ежедневно в 00:00 по Москве;
каждый час выполняется повторная проверка и синхронизация состава на случай сбоев Google.
Если бот был выключен на смене месяца, он подготовит лист после запуска.
Автоматические напоминания игрокам о боссах отключены; планировщик обслуживает обновление таблицы.
При первом обращении к таблице новый месяц также создаётся автоматически.
Оформление и формулы копируются из шаблона. Даты, отметки посещений, ники шаблона,
примечания и ручные капитанские в новой копии очищаются; затем добавляются все
подтверждённые игроки из базы бота по разделам классов. Шаблон и прошлые месяцы сохраняются.
Если подготовка новой копии не удалась, она удаляется и создание можно повторить.

`/sync_pa` добавляет подтверждённых пользователей в свободные строки нужных классов текущего месяца.
Новые игроки занимают свободные строки с подготовленными формулами.
Если раздел заполнен, бот попросит добавить строку с формулами вместо перезаписи игроков.
После подтверждения заявок синхронизация выполняется автоматически; `/start` синхронизирует профиль игрока.
Кнопка «Обновить состав в таблице» в разделе «Состав клана» остаётся для ручного повтора;
при смене месяца нажимать её не требуется.

Администратор меняет ник и класс через «Панель администратора» → «Состав клана»
кнопками «Изменить ник игрока» и «Изменить класс игрока».
Изменение ника сохраняет отметки; смена класса переносит отметки, примечание и капитанские
в свободную строку нового класса, сохраняя формулы обеих строк. Если таблица недоступна или перенос
небезопасен, профиль не меняется. Прежние ники сохраняются в SQLite для синхронизации новых месяцев.
При повторяющемся нике отчёт и запись явки сообщают о конфликте; дубликаты исправляет администратор.

## Фото и явка

Панель администратора → Отметить посещение → мероприятие → дата → скриншоты → проверка.
Дата выбирается кнопками «Сегодня», «Вчера» либо вводится как `ДД.ММ.ГГГГ` или `ДД.ММ`.
Разрешены даты текущего месяца до сегодняшнего дня включительно по московскому времени.
Первого числа кнопка «Вчера» скрыта. Список дат не зависит от заголовков Google-таблицы.
При подтверждении дата и отметки записываются одним запросом. Повторная загрузка
на то же мероприятие и дату использует ту же колонку. Даты с уже сохранёнными отметками сохраняются.
Для новой даты используется пустая колонка соответствующей половины месяца:
РБ — 7+7, Комендант — 2+3, Баньши — 2+2, ГВГ — 2+2 в текущем шаблоне.
Сначала используется пустая колонка, затем разрешается заменить старую плановую дату,
под которой нет отметок. Колонки с отметками или формулами не перезаписываются. Если свободных колонок
в нужной половине месяца нет, бот сообщит об этом; расширять разметку нужно вместе с формулами.
На каждом экране показаны мероприятие, выбранная дата и номер шага.
Загрузите все скриншоты и нажмите «Все скриншоты загружены».
Бот объединит игроков без повторов. Верхний игрок каждого скриншота считается ПЛ;
в одной загрузке может быть несколько ПЛ. Неопределённые ники пропускаются с предупреждением
и рекомендацией отметить их вручную. Если верхний ник неизвестен, следующий игрок ПЛ не становится.
Автоматическое сопоставление требует совпадения ника без учёта регистра и пробелов по краям;
похожие имена не подставляются автоматически.
Проверьте итоговый список и нажмите «Сохранить посещение». До подтверждения отметки не записываются.
«Назад» с проверки возвращает к загрузке дополнительных скриншотов. Можно также вернуться
к дате и мероприятию: загруженные скриншоты сохраняются внутри операции, а выбранные
мероприятие и дата повторно отображаются перед сохранением.
После записи доступны «Отметить другое мероприятие» и «Панель администратора».
ПЛ получают `2`, участники `1`. Повторная запись в ту же дату не создаёт дополнительного посещения
и не уменьшает `2` до `1`. Исправление ошибочной отметки выполняется вручную в таблице.

Зарплата читается из результатов формул `зп 1/2` и `зп 2/2`; бот не заменяет формулы своим расчётом.
OCR.space получает отправленное изображение для распознавания.

## Личные отчёты и меню

«Моя зарплата» (`/mysalary`) показывает обе половины текущего месяца, капитанские и сумму половин.
В текущем шаблоне капитанские включены в первую половину; повторно к итогу они не прибавляются.
Пустые значения и ошибки формул отображаются явно, без подмены нулём.
«Мои посещения» (`/myactivity`) показывает посещения по мероприятиям, число ПЛ, баллы
и показатели `АКТИВКА 1/2`. Отметка `2` означает одно посещение в роли ПЛ и два балла.
Администратор видит зарплаты всего состава через «Зарплаты игроков».

В панели администратора сразу доступны отметка посещений, заявки игроков, состав клана,
опросы ГВГ, зарплаты, заявки на кешбек и ссылка «Открыть таблицу».
Названия и совместимость со старыми клавиатурами заданы в `bot_ui.py`.

«← Назад» возвращает на предыдущий шаг формы, а из раздела — в родительское меню.
«Отменить загрузку/редактирование/опрос/заявку» и `/cancel` прекращают текущую операцию
и возвращают в её раздел. «Главное меню» и `/menu` закрывают ввод и открывают начальный экран.
Переход на другую кнопку меню также закрывает текущую форму.
Ранее отправленные кнопки со старыми названиями продолжают работать.
«Опрос ГВГ» позволяет открыть текущий опрос и изменить ответы. Они сохраняются после подтверждения;
к предыдущему вопросу можно вернуться кнопкой «Назад». Отмена прохождения не меняет уже сохранённые ответы;
кнопки закрытого опроса не принимают новые ответы. Ручной ответ администратора за зарегистрированного
игрока обновляет его ответы и список не ответивших.
«Выгрузить ответы в таблицу» в разделе «Опросы ГВГ» сохраняет ответы на отдельные листы `Опрос ID-номер · встреча`.
Кеш-заявка обрабатывается один раз, после решения игрок получает уведомление.

## Проверка

`python -m unittest -v test_flows test_sheet_layout test_buttons test_navigation test_automation`

Тесты используют временную SQLite и поддельную таблицу; Telegram, OCR и Google API не вызываются.
